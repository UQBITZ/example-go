# example-go

Servidor HTTP em Go (só biblioteca padrão) publicado na [UQBITZ](https://uqbitz.com) pela CLI.

- A plataforma detecta Go pelo `go.mod`, compila com `go build -o app .` e executa `./app`.
- O app escuta na porta de `$PORT` (a plataforma define `8080`).

```bash
go run .
```
